# PRD — Local Maps Pack (Product Requirements Document)

## 1. Objectif Produit
Fournir une brique logicielle Grade Gold dans le domaine **Cartographie & Géolocalisation** (archétype `MAPS`), utilisable immédiatement en production. Le produit adresse le problème suivant : Les applications carto manquent de layers personnalisables, de recherche par catégorie contextuelle (restaurants, parkings), et de calcul d'itinéraire multimodal (voiture, vélo, pied).

## 2. Fonctionnalités Spécifiées

### F01 — Vue carte interactive (Leaflet/MapLibre) avec zoom, pan, et rotation
- **Objectif** : Vue carte interactive (Leaflet/MapLibre) avec zoom, pan, et rotation.
- **Préconditions** : session utilisateur active (sauf endpoints publics) ; données préchargées ou fetch à la demande.
- **Scénario nominal** : l'utilisateur interagit via `MapView`, l'API répond en < 200ms, l'UI se met à jour optimistement.
- **Scénarios d'erreur** : toast d'erreur + retry automatique sur 500/503 ; état vide explicite si aucune donnée ; validation Zod côté client avant envoi.
- **Critères d'acceptation** :
  - Skeleton affiché pendant le chargement (< 200ms).
  - Feedback visuel immédiat (hover, focus, transition).
  - Conformité WCAG AA (contrastes, navigation clavier, ARIA).
  - Persistance D1 vérifiée par test d'intégration.

## 3. Pages de l'application
- `/`
- `/map`
- `/place/:id`
- `/route`
- `/favorites`
- `/collections/:id`
- `/nearby`

## 4. Endpoints API
- `GET /api/places?category=&lat=&lng=&radius=`
- `GET /api/places/:id`
- `GET /api/route?from=&to=&mode=`
- `POST /api/favorites`
- `GET /api/favorites`
- `GET /api/search?q=`

## 5. Store global (state shape)
```typescript
places[], currentPlace, userLocation, route{from, to, mode, steps}, favorites[], activeLayers[]
```

## 6. Interfaces TypeScript principales
```typescript
Place {id, name, category, location{lat, lng}, address, rating, photos[], hours{}, description}, Route {id, from, to, mode, distance, duration, steps[]}, Favorite {id, placeId, collectionId, addedAt}
```

## 7. Contraintes Non Fonctionnelles
- **Accessibilité** : conformité WCAG AA (navigation clavier complète, contrastes validés, ARIA approprié).
- **Sécurité** : headers CSP stricts, protection CSRF, requêtes préparées D1 contre les injections SQL, sanitisation XSS des entrées utilisateur.
- **Performance** : bundle JS < 200 KB gzip, lazy-loading des routes, cache HTTP stale-while-revalidate.
- **Observabilité** : logs structurés JSON, métriques temps-réel, Sentry pour les erreurs front.
- **Internationalisation** : interface en français par défaut, structure i18n prête (fr, en).
