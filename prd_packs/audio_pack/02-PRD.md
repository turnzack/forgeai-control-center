# PRD — Audio Pack (Product Requirements Document)

## 1. Objectif Produit
Fournir une brique logicielle Grade Gold dans le domaine **Audio & Podcast Player** (archétype `AUDIO`), utilisable immédiatement en production. Le produit adresse le problème suivant : Les lecteurs audio web manquent de waveform interactif, de queue persistante entre sessions, de gestion des playlists collaboratives, et de raccourcis clavier pour le contrôle sans quitter la page.

## 3. Pages de l'application
- `/`
- `/library`
- `/playlist/:id`
- `/track/:id`
- `/upload`
- `/favorites`
- `/queue`

## 4. Endpoints API
- `GET /api/tracks?playlist=&mood=`
- `POST /api/tracks/upload`
- `GET /api/playlists`
- `POST /api/playlists/:id/tracks`
- `POST /api/tracks/:id/favorite`
- `GET /api/history`

## 5. Store global (state shape)
```typescript
currentTrack, queue[], playlists[], favorites[], history[], playerState{playing, position, volume, repeat, shuffle}
```

## 6. Interfaces TypeScript principales
```typescript
Track {id, title, artist, album, duration, audioUrl, coverImage, peaks[], mood, playsCount}, Playlist {id, name, coverImage, trackIds[], collaborative, ownerIds[]}, PlayerState {trackId, position, playing, volume, repeat, shuffle}
```

## 7. Contraintes Non Fonctionnelles
- **Accessibilité** : conformité WCAG AA (navigation clavier complète, contrastes validés, ARIA approprié).
- **Sécurité** : headers CSP stricts, protection CSRF, requêtes préparées D1 contre les injections SQL, sanitisation XSS des entrées utilisateur.
- **Performance** : bundle JS < 200 KB gzip, lazy-loading des routes, cache HTTP stale-while-revalidate.
- **Observabilité** : logs structurés JSON, métriques temps-réel, Sentry pour les erreurs front.
- **Internationalisation** : interface en français par défaut, structure i18n prête (fr, en).
