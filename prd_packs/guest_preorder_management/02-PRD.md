# PRD — Preorder Manager (Product Requirements Document)

## 1. Objectif Produit
Fournir une brique logicielle Grade Gold dans le domaine **E-commerce & Boutique en Ligne** (archétype `ECOMMERCE`), utilisable immédiatement en production. Le produit adresse le problème suivant : Les boutiques en ligne actuelles souffrent de tunnels d'achat longs, d'une recherche produit peu pertinente, d'un manque de filtres adaptés (taille, couleur, prix) et d'une gestion d'inventaire désynchronisée entre le panier et le stock réel.

- `/wishlist`

## 4. Endpoints API
- `GET /api/products?category=&minPrice=&maxPrice=&sort=&page=`
- `GET /api/products/:slug`
- `POST /api/cart/items`
- `GET /api/cart`
- `POST /api/orders`
- `GET /api/orders/:id`
- `POST /api/products/:slug/reviews`

## 5. Store global (state shape)
```typescript
products[], cart{items[], subtotal, discount}, user, orders[], wishlist[], filters{category, priceRange, brands, sort}
```

## 6. Interfaces TypeScript principales
```typescript
Product {id, slug, name, price, compareAtPrice, images[], category, brand, attributes{size[], color[]}, stock, rating, reviewCount}, CartItem {productId, quantity, variant}, Order {id, items[], total, status, shippingAddress, createdAt}
```

## 7. Contraintes Non Fonctionnelles
- **Accessibilité** : conformité WCAG AA (navigation clavier complète, contrastes validés, ARIA approprié).
- **Sécurité** : headers CSP stricts, protection CSRF, requêtes préparées D1 contre les injections SQL, sanitisation XSS des entrées utilisateur.
- **Performance** : bundle JS < 200 KB gzip, lazy-loading des routes, cache HTTP stale-while-revalidate.
- **Observabilité** : logs structurés JSON, métriques temps-réel, Sentry pour les erreurs front.
- **Internationalisation** : interface en français par défaut, structure i18n prête (fr, en).
