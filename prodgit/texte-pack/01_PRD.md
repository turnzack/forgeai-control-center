# Product Requirements Document (PRD)

## Mission Principale
Projet souverain ✍️ PACK TEXTE basé sur l'archétype **universal_app**.

## Piliers Validés
- **Pilier 1:** Conformité Open-Source SPDX (Licences MIT / Apache 2.0 certifiées).
- **Pilier 2:** Architecture à 4 étages (Types, Services, Composants UI, Shell App).
- **Pilier 3:** Services Métiers Réactifs avec Persistance Locale (Pattern Observer / Pub-Sub).
- **Pilier 4:** UI Kit Shadcn-like & Couche d'Animation Embarquée (3D / Motion).
